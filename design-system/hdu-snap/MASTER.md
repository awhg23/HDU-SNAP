# HDU-SNAP 桌面端设计系统

> 本文件由 `ui-ux-pro-max` 的 Claymorphism、Nature Distilled、Editorial Grid 与可访问性检索结果综合而成。用户明确要求优先于数据库默认推荐：不得使用蓝白 SaaS/商务仪表盘风格。

## 设计气质

- 定位：本地运行的词汇学习搭子，不是企业后台。
- 关键词：温暖、安静、友好、轻触感、清楚、不过度幼稚。
- 风格组合：克制 Claymorphism + Nature Distilled + 少量纸张编辑感。
- 动效：只做 180–220ms 的颜色、边框和阴影过渡；不使用缩放悬浮、滚动劫持或持续动画。

## 色彩

| 角色 | 色值 | 用途 |
|---|---:|---|
| 奶油画布 | `#F2EADC` | 页面背景 |
| 暖纸面 | `#FFFAF0` | 卡片、表单、工具栏 |
| 深橄榄 | `#343C2B` | 侧栏、主要深色结构 |
| 鼠尾草 | `#72805C` | 正常状态、自然辅助色 |
| 陶土橙 | `#C45F3C` | 主操作、当前焦点 |
| 芥末黄 | `#D29A35` | 进度、轻强调 |
| 暖墨色 | `#342F29` | 正文和标题 |
| 危险红 | `#A84940` | 删除、错误、停止 |

约束：不使用蓝色作为品牌色、主按钮、选中态或进度色；不同状态除颜色外还必须有文字或图标。

## 字体

- 标题：`Avenir Next Rounded` / `Avenir Next` / `PingFang SC`。
- 正文：`Avenir Next` / macOS 系统字体 / `PingFang SC`。
- 不加载网络字体，保证离线 App 首屏稳定。
- 页面主标题 28–40px，卡片标题 15–27px，正文 12–14px，辅助信息不低于 9px。

## 形状、边框与阴影

- 卡片圆角：18–24px，并允许四角轻微不对称，形成纸张和手作感。
- 控件圆角：10–15px；状态标签使用胶囊形。
- 卡片边框：暖灰棕 `#D9C9B4`，禁止不可见的白色透明边框。
- 卡片阴影：柔和环境阴影叠加 3–5px 的低对比“落纸”阴影。
- 静态卡片不显示指针光标，也不添加伪交互悬浮效果。

## 布局不变量

- 应用最小尺寸：1100 × 700。
- 左侧导航占用 220px 网格，内部为带 12px 外边距的 196px 浮动侧栏。
- 学习页浏览工具栏固定 64px，运行栏固定 72px；原生 `WebContentsView` 从 `y=136` 开始。
- 412px 移动答题画布始终在侧栏以外的主内容区水平居中。
- 答题详情面板贴右侧 12px，宽度在 214–280px 自适应，不覆盖答题画布。
- 普通页面内容保持一致的 34–46px 页面留白，表格和设置区域使用统一最大宽度。

## 组件规则

### 导航

- 使用统一的内嵌 Lucide 风格线性 SVG，不使用 Emoji。
- 当前项采用芥末浅底和陶土侧标；锁定项同时显示锁图标并禁用。
- 提供“跳到主要内容”的键盘跳过链接。

### 按钮与表单

- 主按钮：陶土橙底、奶油文字；次按钮：暖纸面；柔和按钮：鼠尾草浅底。
- 危险操作必须使用文字和红色边框，不只依赖颜色。
- 所有可点击元素显示指针光标，禁用项恢复默认光标并降低透明度。
- 键盘焦点使用清晰的陶土色 3px 外环。

### 卡片与表格

- 首页、引导页可以使用学习插画；记录、设置、诊断保持信息优先。
- 表格表头使用暖灰纸面；行悬浮只改变背景色，不移动布局。
- 空状态包含统一 SVG 图标、标题和一句操作提示。

### 学习页

- 内嵌网页内容不覆盖、不重绘，App UI 只负责其外围工具栏和状态。
- 运行状态、题量和操作保持在单行运行栏中。
- 答题详情最新一题置顶，独立滚动；方法颜色采用芥末、鼠尾草、梅紫、陶土和危险红，不使用蓝色。

## 可访问性与交付检查

- 正文与背景对比度至少 4.5:1。
- 图标按钮必须有 `aria-label` 和 `title`。
- 表单必须关联可见标签或 `aria-label`。
- 所有功能可通过键盘访问，视觉顺序与 Tab 顺序一致。
- 尊重 `prefers-reduced-motion`，不得强制动画。
- 不使用 Emoji 代替 UI 图标，不使用网络字体，不产生水平滚动。
- 在 1100px 最小宽度和 1440px 宽度分别检查布局。
