# 产品需求文档：HDU-SNAP 第二阶段——一体化 macOS App - V1.5

- 文档编号：PRD-001
- 状态：需求已确认
- 初始确认：2026-08-09
- 最近修订：2026-08-17
- 目标平台：Apple Silicon、macOS 13+

V1.1 取消多账号档案、身份识别和账号隔离，改为一份跨重启保留的网页登录会话；批次记录不再保存姓名或学号。同时增加手动补丁录入，并保留旧版 `patch_rules.jsonc`/JSON/JSONC 导入。

V1.2 将当前确认完善的 `patch_rules.jsonc` 作为安装包内置补丁基线。新安装完整播种，升级仅补齐缺失题目且不覆盖用户手动修正；打包流程必须自动校验安装包内文件与发布基线一致。

V1.3 取消 macOS 桌面端的调试模式、自动复盘和调试逐题记录。桌面端只保留正常答题；纠错统一通过内置补丁、手动添加和旧版 JSON/JSONC 补丁导入维护。第一阶段 CLI/插件的调试协议暂时保留，不属于本次删除范围。

V1.4 将固定移动答题画布左移，并在其右侧增加“本次答题详情”滚动面板。面板按最新优先显示本次运行的题号、题目、所选答案、答案文本、决策来源和可选置信度；这些逐题信息只存在于当前进程内，不写入批次记录或磁盘。

V1.5 将 412px 移动答题画布恢复为主内容区水平居中；“本次答题详情”面板独立贴近窗口右侧，宽度随窗口在 214–280px 范围内自适应。桌面窗口最小宽度调整为 1100px，详情面板不得挤压或覆盖答题画布。

## 1. 综述（Overview）

### 1.1 项目背景与核心问题

第一阶段已经完成后端与 Chrome 插件重构，并通过真实登录和答题验收，但用户仍需安装 Python 环境、项目依赖和 Chrome 插件，并分别管理后端与网页自动化。

第二阶段将产品重构为完全自包含的 macOS App。用户在 App 内手动登录、导航、配置和运行答题，并完成人工提交、补丁维护、记录管理和诊断，不再依赖 Chrome 插件或外部 Python/Node 环境。App 只保留一份网站会话，不识别或记录账号身份。

目标用户为获得当前私有 GitHub 仓库访问权的小范围同学。首版仅支持 Apple Silicon 和 macOS 13+，以未签名 DMG 交付。

### 1.2 核心用户旅程

1. **获取与安装**：下载 DMG、安装、手动通过系统安全确认。
2. **首次配置**：完成严格自检，可选配置 DeepSeek Key。
3. **登录与导航**：使用 App 内唯一的持久会话手动登录并进入题目页。
4. **设置与启动**：设置题量，识别题目页后手动开始。
5. **自动答题**：查看进度，必要时暂停、继续或停止。
6. **最终确认**：最后一题挂起，用户亲自检查和提交。
7. **结果与维护**：生成批次摘要，并通过设置页维护纠错补丁。
8. **诊断与维护**：管理记录、迁移、日志、诊断和版本更新。

### 1.4 成功标准

- DMG 安装后不依赖外部 Python、Node、Chrome 或浏览器插件。
- 支持 Apple Silicon、macOS 13+。
- 支持一份跨 App 重启保留的网页登录会话；不识别或记录姓名、学号等账号身份。
- 正常答题完成真实站点验收。
- 所有路径均不会自动提交最终答题结果。
- 密码、Cookie、会话令牌和 DeepSeek Key 不进入日志、记录、诊断包或网页。
- 旧版数据可迁入，升级过程有备份和失败保护。
- Mac App 验收通过后删除旧插件、CLI、脚本和本地 API 入口。

### 1.5 公共接口与核心数据语义

- 保留跨平台 **Solver** 边界：输入题目和 A–D 选项，输出答案、决策来源、可选置信度和诊断详情。
- 跨平台核心继续保留现有协议模型及语义：solve_item、batch_complete、review_results、decision、error、batch_summary、review_results_ack；Mac App 不调用 review_results/review_results_ack。
- Mac App 主路径不开放本机 HTTP/WebSocket 端口，直接通过应用服务调用答题核心。
- 批次状态固定包含：已完成、已中止、异常中止、未确认提交。
- 网站数据使用单一持久容器；不保存账号密码，也不建立账号档案。
- 批次记录保存目标/实际题量、时间、耗时、状态、提交确认方式、决策统计和可选站点成绩，不保存模式、逐题内容、姓名、学号或其他登录身份。学习页可以在内存中展示本次逐题详情，退出 App 后即丢弃。

## 2. 用户故事详述（User Stories）

### 阶段一：安装、首次启动与任务配置

---

#### US-01：作为首次使用者，我希望安装并验证完整的 Mac App，以便无需开发环境即可使用

**价值陈述**

- **作为** 小范围测试用户
- **我希望** 通过一个自包含 App 完成安装和首次检查
- **以便于** 不再安装 Python、Node、Chrome 插件或项目源码

**业务规则与逻辑**

1. 前置条件为 Apple Silicon、macOS 13+。
2. 用户通过未签名 DMG 安装，并按文档手动允许系统打开。
3. 首次启动依次进入欢迎、系统自检、初始配置和完成四步。
4. 系统版本、内置答题核心、词典、向量模型、数据目录、网页组件和目标站点网络必须全部通过。
5. DeepSeek 可跳过；填写后必须验证成功，Key 只写入 macOS 钥匙串。
6. 必需检查失败时禁止进入主界面，允许重试和导出诊断。
7. 后续启动直接进入首页；升级或资源损坏时重新进入自检。

**验收标准**

- **GIVEN** 支持的 Mac 且所有组件完整，**WHEN** 完成自检并跳过 Key，**THEN** 可进入首页。
- **GIVEN** 向量模型缺失或目标站点不可连接，**WHEN** 执行自检，**THEN** 显示具体阻断原因且不能继续。
- **GIVEN** 用户填写无效 Key，**WHEN** 验证失败，**THEN** 不保存 Key，可修改或清空后跳过。
- **GIVEN** 已完成首次引导，**WHEN** 再次正常启动，**THEN** 不重复显示欢迎页。

#### US-02：作为答题用户，我希望在首页配置题量，以便创建明确可控的批次

**业务规则与逻辑**

1. 首页采用左侧导航：主页、学习、记录、设置、诊断。
2. 每次 App 启动默认 100 题，不恢复上次值。
3. 题量接受任意大于 0 的整数。
4. 点击“进入学习站点”仅锁定当前批次配置并进入学习页，不立即答题。

**验收标准**

- **GIVEN** 题量为正整数，**WHEN** 点击进入学习站点，**THEN** 创建待就绪批次并进入唯一的持久网站会话。
- **GIVEN** 题量非法，**WHEN** 查看首页，**THEN** 显示就地错误且禁用进入按钮。
- **GIVEN** 批次已经运行，**WHEN** 尝试回首页重配，**THEN** 全局导航保持锁定。

### 阶段二：内嵌网页登录与单一会话

---

#### US-03：作为答题用户，我希望在 App 内保留一份安全登录会话，以便减少重复登录且不记录身份

**业务规则与逻辑**

1. 学习页是单页轻量浏览器，提供地址栏、前进、后退、刷新和返回学习站点。
2. 支持任意 HTTPS；HTTP 每次加载前提示风险；证书错误直接阻止。
3. 新窗口在当前页面打开，不实现多标签页。
4. 下载使用 macOS 保存对话框，不自动打开。
5. 自动答题只对支持的 HDU 域名启用。
6. App 使用唯一的持久网站数据容器，Cookie 和站点存储跨 App 重启保留。
7. App 不提取姓名、学号，不创建账号档案，也不在批次或导出中保存登录身份。
8. 用户可在设置中清除唯一的网站登录数据；清除后需要重新手动登录，但不删除批次记录。
9. 从 V1.0 升级时保留一个既有登录分区以减少重新登录；账号档案和历史批次中的姓名学号在备份后移除。

**验收标准**

- **GIVEN** 用户已手动登录，**WHEN** 重启 App 并进入学习页，**THEN** 唯一会话保持登录。
- **GIVEN** 用户进入个人中心，**WHEN** 页面显示姓名学号，**THEN** App 不解析、不保存且不在本地 UI 展示这些字段。
- **GIVEN** 用户清除网页登录数据，**WHEN** 再次打开学习站点，**THEN** 站点要求重新登录而批次记录仍保留。
- **GIVEN** 用户访问非支持域名，**WHEN** 页面加载，**THEN** 浏览正常但所有自动化能力禁用。

### 阶段三：自动答题与运行控制

---

#### US-04：作为答题用户，我希望观察并控制自动答题过程，以便在异常时安全接管

**业务规则与逻辑**

1. 网页使用固定移动端身份和逻辑画布，按窗口等比缩放。
2. 保持“补丁规则 → 词典 → 向量 → DeepSeek/确定性兜底”的决策顺序、阈值和随机延迟。
3. 只有识别题目页后，开始按钮才启用。
4. 运行中锁定地址栏、网页点击和左侧导航。
5. 412px 固定移动画布在侧栏以外的主内容区水平居中；独立的“本次答题详情”面板贴近窗口右侧，宽度在 214–280px 范围内自适应，不得挤压或覆盖画布。最新一题置顶，可滚动查看本次全部题号、题目、所选答案、答案文本、决策来源和可选置信度。
6. 逐题详情只保存在当前 Electron 进程内，不写入状态文件、批次记录或导出；新建批次时清空。
7. 切换 App 或最小化时继续运行。
8. 锁屏、睡眠或页面不可执行时自动暂停，恢复后需用户手动继续。
9. 同一题失败自动重试 3 次，耗尽后错误暂停。
10. 暂停、继续或重试前必须重新读取当前页面，不重放旧点击。
11. 停止需二次确认，保存为已中止且不可恢复。
12. 崩溃或强制退出后，下次启动保存为异常中止，不恢复批次。

**验收标准**

- **GIVEN** 已识别题目页，**WHEN** 用户点击开始，**THEN** 页面锁定并开始显示答题进度。
- **GIVEN** 已完成多道题，**WHEN** 查看画布右侧，**THEN** 最新答案置顶且可滚动查看本次全部决策信息。
- **GIVEN** App 退出并重新启动，**WHEN** 查看批次记录或导出，**THEN** 不包含右侧面板的逐题内容。
- **GIVEN** App 被最小化，**WHEN** 页面仍可执行，**THEN** 批次继续。
- **GIVEN** 系统进入睡眠，**WHEN** 恢复，**THEN** 批次保持暂停，必须人工继续。
- **GIVEN** 同题连续失败 3 次，**WHEN** 重试耗尽，**THEN** 显示错误暂停，只允许重试当前题或停止。

### 阶段四：最终题与人工提交

---

#### US-05：作为答题用户，我希望最后一题自动挂起，以便亲自检查并提交

**业务规则与逻辑**

1. 达到目标题量时只选择最后一题答案，绝不触发提交按钮。
2. 挂起后网页解锁，用户亲自检查和提交。
3. 如果实际还有题，用户可输入正整数增加目标并继续。
4. 用户提交后自动识别结果页，最长等待 15 秒。
5. 超时后显示“我已提交”，二次确认只更新本地状态，不操作网页。
6. 提交确认后生成完成记录。
7. 挂起时关闭或异常退出，批次保存为未确认提交。
8. 正常结果展示本地摘要；站点成绩可识别时附加显示，识别不到不算失败。

**验收标准**

- **GIVEN** 达到目标题量，**WHEN** 最后一题完成决策，**THEN** 只选择答案并挂起，提交按钮未被自动触发。
- **GIVEN** 用户增加 10 题，**WHEN** 确认继续，**THEN** 目标更新并在新目标处再次挂起。
- **GIVEN** 用户手动提交，**WHEN** 15 秒内识别结果页，**THEN** 自动结算批次。
- **GIVEN** 15 秒未识别，**WHEN** 用户二次确认已提交，**THEN** 只更新本地完成状态。

### 阶段六：批次记录

---

#### US-07：作为答题用户，我希望查看和导出批次记录，以便追踪使用情况和问题

**业务规则与逻辑**

1. 批次记录不保存姓名、学号或其他登录身份。
2. 默认按时间倒序，每页 50 条。
3. 支持按状态和日期筛选。
4. 所有批次只保存摘要，不保存逐题内容。
5. 全局最多保留 1000 批，超限自动删除最旧批次。
6. 支持单条和批量删除，二次确认且不可恢复。
7. 支持导出当前筛选范围的摘要 CSV 和 JSON。
8. 导出不包含姓名、学号、模式或调试逐题字段，保存前必须提示记录数据风险。

**验收标准**

- **GIVEN** 写入第 1001 批，**WHEN** 保存完成，**THEN** 最旧批次被清理，纠错规则不受影响。
- **GIVEN** 用户导出 JSON，**WHEN** 选择保存位置，**THEN** 文件不含账号身份、模式或调试逐题字段。
- **GIVEN** 删除批次，**WHEN** 二次确认，**THEN** 记录删除但纠错补丁保持生效。

### 阶段七：设置、补丁和旧版迁移

---

#### US-08：作为维护用户，我希望集中管理会话、Key、纠错和旧数据，以便安全迁移和维护 App

**业务规则与逻辑**

1. 学习首页只能在两个支持站点之间选择。
2. DeepSeek Key 可测试、更换或移除；更换必须验证成功后才覆盖旧值。
3. 可清除唯一的网站登录数据；清除登录不删除历史记录。
4. 纠错补丁可查看、手动添加、删除及 JSON/JSONC 导入、JSON 导出。
5. 手动添加至少要求题目和正确答案；错误答案与备注可选。相同题目冲突时必须确认后才替换。
6. 纠错导入先预览重复与冲突，确认后合并；可直接选择旧版 `patch_rules.jsonc`。
7. 用户可选择旧项目目录，迁入根目录补丁和 Key。
8. 不迁移 Chrome Cookie，不修改或删除旧项目文件。
9. 不迁移旧版调试记录或调试逐题内容。
10. 迁移通过来源指纹保持幂等。
11. 支持分类清理及输入确认文本后的全部重置。
12. 全部重置清除用户数据并回到首次引导；内置词典和内置默认资源随 App 保留。

**验收标准**

- **GIVEN** 新 Key 验证失败，**WHEN** 用户尝试保存，**THEN** 原 Key 保持不变。
- **GIVEN** 填写题目和正确答案，**WHEN** 保存手动补丁，**THEN** 规则立即出现在列表并影响后续答题。
- **GIVEN** 手动补丁与已有题目冲突，**WHEN** 用户未确认替换，**THEN** 旧规则保持不变。
- **GIVEN** 同一旧目录重复导入，**WHEN** 第二次确认迁移，**THEN** 不重复写入纠错。
- **GIVEN** 旧数据损坏，**WHEN** 扫描目录，**THEN** 展示可理解错误，不修改现有 App 数据。
- **GIVEN** 用户执行全部重置，**WHEN** 输入正确确认文本，**THEN** 清除用户数据并返回首次引导。

### 阶段八：诊断与版本维护

---

#### US-09：作为测试用户，我希望导出诊断并检查新版本，以便向开发者反馈问题并安全升级

**业务规则与逻辑**

1. 不接入遥测、Sentry 或自建上传服务，不自动发送任何数据。
2. 日志与崩溃信息只保存在本地。
3. 诊断 ZIP 包含题目选项、决策详情、网页快照、日志、崩溃堆栈和组件状态；App 状态和批次记录不包含账号身份，但网页快照可能包含页面可见的个人信息。
4. 密码、Cookie、会话令牌、DeepSeek Key 和钥匙串内容永远排除。
5. 导出前必须勾选确认报告可能包含页面个人信息与答题数据。
6. 日志按 30 天或 100 MB 上限滚动清理。
7. App 每 24 小时最多检查一次公开只读版本清单，也支持手动检查。
8. 默认稳定频道，可切换包含 prerelease 的测试频道。
9. 源码和 DMG 位于私有仓库；使用者必须拥有仓库访问权。
10. 公开版本清单不包含源码、密钥或私有资源，只包含版本、频道、说明摘要、SHA-256 和私有 Release 链接。
11. App 不保存 GitHub Token，不自动下载或替换自身。
12. 数据结构升级前自动备份，保留最近 3 份。
13. 迁移失败时阻止运行并允许恢复备份或导出诊断。
14. 旧版 App 遇到更高数据版本时阻止运行并提示升级。

**验收标准**

- **GIVEN** 用户未勾选敏感内容确认，**WHEN** 尝试导出诊断，**THEN** 导出按钮保持禁用。
- **GIVEN** 生成完整诊断包，**WHEN** 检查内容，**THEN** 包含运行上下文但不含任何密钥、Cookie 或会话令牌。
- **GIVEN** 距上次检查不足 24 小时，**WHEN** 启动 App，**THEN** 不重复请求版本清单。
- **GIVEN** 用户无私有仓库权限，**WHEN** 打开 Release 链接，**THEN** App 提示需要 GitHub 访问权且不要求输入 Token。
- **GIVEN** 数据迁移失败，**WHEN** 重新启动，**THEN** 主流程被阻止并提供最近备份恢复入口。

## 3. 测试与发布验收

### 3.1 自动化测试

- 首次引导、自检、Keychain、必需/可选能力分流。
- 单一持久会话、清除登录、升级时沿用一个旧分区，以及身份字段从状态和记录中移除。
- 任意网页、HTTP 警告、证书错误、新窗口、下载和非支持域名禁用自动化。
- 固定移动画布下的题目提取、决策、随机延迟、暂停、继续、停止和三次重试。
- 最后一题在任何 DOM fixture 下均不会触发提交。
- 15 秒提交识别与人工确认兜底。
- 桌面 UI、IPC、站点适配器和批次状态中不存在调试模式或自动复盘入口。
- 记录筛选、1000 批滚动清理、无身份/模式/调试字段的 CSV/JSON 导出和不可恢复删除。
- 手动补丁、JSON/JSONC 补丁导入、旧补丁迁移、重复导入、损坏数据和 Key 冲突。
- 诊断包敏感信息扫描、日志轮转、版本频道、备份迁移和降级阻断。
- DMG 在干净的 Apple Silicon、macOS 13+ 环境中不依赖外部开发工具。

### 3.2 人工验收

- 验证登录会话跨重启保留、清除登录后需要重新登录，且 UI、状态和批次导出均不记录姓名学号。
- 完成正常模式真实答题，并验证最后一题人工提交。
- 验证睡眠暂停、最小化继续、网络异常、异常退出和重新启动。
- 从第一阶段项目目录迁移真实纠错和 Key，确认调试记录不会迁入。
- 覆盖安装新版 DMG，验证数据保留、备份和更新提示。
- 验证无仓库权限和具有仓库权限用户的私有 Release 行为。

### 3.3 旧版退场顺序

1. 在保留现有插件与 CLI 的前提下完成 Mac App 开发和行为对照。
2. Mac App 自动化测试、DMG 测试和真实正常答题均通过。
3. 完成旧版数据迁移验证。
4. 删除 extension、旧安装/启动脚本、main.py、CLI 和本地 HTTP/WebSocket 入口。
5. 保留领域层、应用层、Solver 接口和版本化协议模型。
6. 更新中文 AGENTS.md、README、技术文档和 macOS 使用指南。

## 4. 明确边界与默认假设

- 本阶段不支持 Intel Mac、macOS 12 及以下。
- 本阶段不做 Developer ID 签名、公证或 App Store 发布。
- 不保存账号身份或密码，不自动登录，不自动提交。
- 不实现多标签页、云同步、远程控制、遥测或自动上传。
- 不实现 Windows 或 Android 客户端。
- 不自动安装更新，不要求用户配置 GitHub Token。
- 桌面端只提供正常答题，且不持久化逐题内容；纠错只通过补丁维护。
- 必须验证目标站点单一持久登录会话、移动布局和 DOM 自动化兼容性。
